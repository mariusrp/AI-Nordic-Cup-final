# Drone training set — what is here, what is not, and how to rebuild it

The detector served in the final (`drone/weights/ft5r_last.pt`) was fine-tuned from the synthetic-trained base
`v2.pt` on three sources. The IMAGES are ~5.4 GB and are deliberately not in git; the LABELS and the label source
are, because they are what we produced and what a reviewer would want to inspect.

## In this directory
- `real_all/labels/train/*.txt` — 3006 YOLO label files, one per training view. `vc*` = views recorded from the
  validation flight (frames 1-249, all 8+ recordings), `hel*` = tiles cut from the 25 supplied Helsinki frames.
- `label_source_table_v2b.json` — the per-frame answer table our offline fusion produced for the validation
  flight. The `vc*` labels are this table projected into each recorded view. It is a PSEUDO-LABEL source:
  multi-model, multi-scale detections fused across frames via the flight homography (`drone/replay/fuse.py`),
  then corrected by eye at native resolution (the override files in `drone/replay/overrides_v*.json`).
- `data_ft6n.yaml.txt` — the dataset definition of the later ft6n experiment (rejected; see drone/LEDGER.tsv).

## Not in git, and why
- `images/` (3.0 GB): 960x540 PNG views recorded from the validation flight. The drone case README explicitly
  allows recording and keeping the validation sequence; re-recording it reproduces them.
- The synthetic set (2.4 GB, `/root/dd/data/yolo_v2` on the pod): generated by `drone/make_synth.py` with fixed
  seeds, so it is reproducible from the code in this repo.

## Rebuild
1. Record the validation flight with `DRONE_RECORD_DIR` set (drone/server.py writes one PNG per view + meta.jsonl).
2. Build the answer table: `drone/replay/` (infer_views.py -> fit_h.py -> fuse.py, see drone/replay/build_v2.sh).
3. Project the table into the recorded views to get the labels here: `drone/bb3/` (see drone/LEDGER.tsv row
   2026-09-20T01:25 for the exact recipe and mix ratio).
4. Train: `drone/bb3/train_ft5.py` from `v2.pt`, 20 epochs, imgsz 1280, batch 8, AdamW lr0 0.001, freeze=10,
   mosaic 0.5, mixup 0.1, mixed 1:3 real:synthetic plus 420 Helsinki tiles.
